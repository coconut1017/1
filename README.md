# 椰子PPTskill

用于依据论文或报告制作中文学术课程PPT，以及配套逐页口语发言稿。

主要做法：

- 先整理原文论证与证据，再决定分页；落实用户指定的模板。
- 排版前审读全部标题，减少冗长结论句和过多的章节编号。
- 在用户指定范围内统一处理页面批注，图片署名紧跟对应图片。
- 依据最终课件的实际页序写讲稿，并渲染检查最终文件。

## 文件位置

技能入口是 [skills/coconut-ppt/SKILL.md](skills/coconut-ppt/SKILL.md)。同一目录包含界面元数据、标题与讲稿参考规则，以及读取PPT页序和文本的检查脚本。

## 使用

将 `skills/coconut-ppt` 放入个人Codex技能目录后，可使用 `$coconut-ppt` 调用。例如：

> 用 $coconut-ppt，依据这份报告和模板制作课程汇报，并配套Word发言稿。

## 持续修订

新的优秀课件可用于提炼版式、图文密度和讲述方面的可复用做法。成品反馈与课堂评价用于修正规则；具体配色、页数和风格不作为所有课件的固定要求。

每次修订通过Git记录新增、调整或删除的规则，保留可以比较和回退的版本。
