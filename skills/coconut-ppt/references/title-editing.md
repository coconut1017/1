# 标题与层级校准

适用于新课件、全篇标题修改，以及用户指出“标题太长”“AI味明显”“编号太多”的情况。局部内容修订只复查有关页面。

## 先看页面的任务

先用一句工作用语写清这一页要完成什么，例如“比较农业面积与农药投入的变化”。再选屏幕标题。工作用语不必全部出现在页面上。

标题常有两种合适形式：

- 短主题，适合介绍对象、过程、比较或方法，如“农业面源污染”“全球取水结构”。
- 短判断，适合有一条突出发现的页面，如“人工储水难抵天然损失”。判断的强度必须与来源一致。

按内容选择，不让连续页面都变成“对象＋机制＋趋势＋限制条件”的长句，也不全部变成同一种抽象名词标题。

长度以一行能放下、听众两三秒能读明白为参考，不靠缩小字号容纳长句，也不为凑字数删掉关键限定。如果主题确实复杂，先检查是否混入两个独立论证单元。

## 本次课程汇报形成的例子

| 原题 | 可采用的短题 | 留在正文或讲稿中的信息 |
| --- | --- | --- |
| 健康淡水系统支撑人类、生态与文化生活 | 淡水系统的价值 | 健康、生态和原住民族文化生活的具体关系 |
| 农业径流输入营养盐、农药与畜牧残留 | 农业面源污染 | 污染物种类及进入水体的路径 |
| 农业用地减少，农药使用量却持续增加 | 农业用地与农药投入 | 研究时期、两项变化及可能解释 |
| 地下水下降加速、减缓与反转并存 | 地下水位变化 | 不同变化的比例、参照期及区域差异 |
| 极端洪水变化分化，全球评估仍受资料限制 | 极端洪水的区域差异 | 洪水量级、频率、资料限制 |
| 药物和PFAS可在处理后残留并保持风险 | 药物与PFAS残留 | 处理后生物活性、环境持久性及风险的确定程度 |

这些是编辑示例，不是可机械套用的标题库。“全球评估受资料限制”等信息从标题移入正文后，仍然需要保留。

## 只读标题时检查什么

把全部标题连读，不看正文：

1. 能否知道每页具体讲什么，相邻页是否分工清楚？
2. 是否重复“通过……改变……”“仍存在……”等句型，或用抽象词代替具体对象？
3. 有无语病、词义堆叠、为了完整而把整段摘要搬上标题？
4. 缩短后有没有把估计写成事实、丢失空间范围或加强判断？
5. 汇报者口头介绍这页时，是否会自然地使用这个标题？

“土地退化通过水文过程改变减少可用水”一类语句应直接重写为清楚的主题，原有机制继续在正文展开。

这里审的是表达和阅读负担，不依据某个词、句式或检测分数判断作者身份。

## 屏幕只保留有用的层级

报告中的 `6.2 → 6.2.1 → 6.2.1.1` 用于查阅定位。课堂内容页通常可以显示为：

- 板块标识：淡水压力。
- 主标题：农业面源污染。
- 正文或图解：具体污染来源与路径。

原编号保留在工作对应表或备注中。目录的一级编号、顶部板块导航、小节标签、主标题各有用途；如果出现重复，优先减少重复信息，而非继续叠加更多标签。导航清楚、可见并与模板一致即可，不另造炫目的编号系统。
